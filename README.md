# kentontechnical-site

Static staging site for Kenton Technical Products.

Generated by `_build/build.py` (Python 3 + Jinja2 + Pillow) from `_build/products.json`, which was extracted from the kentons.biz WooCommerce catalogue. Editorial copy lives in `_build/content.py`. Do not hand-edit the generated HTML.

Set `STAGING=0` when building to remove the noindex tag and open robots.txt for go-live. `redirects-from-kentons-biz.csv` maps every old kentons.biz URL to its new path for 301 redirects at cut-over.
